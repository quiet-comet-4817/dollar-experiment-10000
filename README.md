# 10,000 × $1 — A Social Experiment

Can 10,000 strangers each voluntarily send $1?

This is a public social experiment about participation and reach.

## Important disclosure

**This is not a charity fundraiser. The project creator keeps any money received.** There is no prize, repayment, financial return, or promised benefit. Participation is entirely optional.

- PayPal: https://paypal.me/ahmadaloul
- Website (once GitHub Pages finishes publishing): https://quiet-comet-4817.github.io/dollar-experiment-10000/

## Progress tracking

The website currently starts at **0 participants / $0**. The progress counter is manual and is not connected to PayPal. Update the figures in `index.html` only when you have a reasonable basis for the count, and make clear that the numbers are manually reported.

## Run locally

Open `index.html` in a browser. It is a static page with no build step and no analytics or tracking scripts.
